## TripleA 简体中文本地化 + macOS DMG 打包

### 背景
- 用户要求：把游戏界面英文全部汉化，打包成 macOS DMG，提交到 fork `https://github.com/eccstartup/triplea`。
- remote 调整：`origin` → fork，`upstream` → 官方 `triplea-game/triplea`。

### 关键发现
- i18n 基础设施极弱：仅 3 个 properties（ui/en/de）、54~61 个 key，只覆盖启动菜单。
- **核心 bug**：`I18nResourceBundle.java:21-26` 原用 `Locale.lookup(getSupportedLanguageRange(), Collator.getAvailableLocales())`，权重最高的 en-US 永远胜出，导致非英语翻译运行时根本不加载（德语也可能一直没生效）。已改为基于 `getActiveLocale()`（默认 zh_CN，可用 `-Dtriplea.language` 覆盖）。
- 玩家可见硬编码英文实际约 640~700 条（非文档说的 12000+，后者含大量内部/功能性字符串）。
- **雷区（禁止直译）**：BattleStepStrings、EndRoundDelegate 的胜负/规则字符串会写入存档、参与 `.contains()` 旧存档判定、switch 分支、地图 XML property key；Constants.java 全是 XML 附件名/资源 ID；玩家名/单位名来自地图 XML 且是实体 ID。这些保持英文以保存档/地图兼容。

### 实施
- 新建 `ui_zh_CN.properties`（61 key 全译）；注册 zh_CN 到 I18nResourceBundle。
- 批量汉化 26 个 Java 文件约 400 处玩家可见字符串（启动器、主框架、菜单条、各阶段面板、设置项、战斗计算器、大厅、战斗面板）。
- 踩坑：翻译文本里用半角 `"` 包中文（如 `"从历史保存游戏"`）会破坏 Java 字符串，改用「」；跨行拼接翻译时误加逗号导致语法错误。教训：批量替换后必须编译验证。
- 格式化 `./gradlew spotlessApply` 后重新编译。

### 构建/打包环境
- 本机原无 JDK。brew cask 装 temurin@25 需 sudo 密码（非交互环境不行）。改用下载 tar.gz 解压到用户目录：`~/.jdks/jdk-25.0.5+8/Contents/Home`，设 JAVA_HOME 指向它即可。
- Gradle wrapper 9.9.0（首次联网下载）。
- 打包路线（无需 install4j 商业 License）：`./gradlew :game-headed:shadowJar` → `jpackage --type app-image` → `hdiutil create -format UDZO` 得 DMG。jpackage 会自动 ad-hoc 签名。
- 打包 JVM 参数：`-Dtriplea.language=zh_CN`、`--add-opens=java.desktop/com.apple.eawt.event=ALL-UNNAMED`、`-Xmx2G`。
- **产物**：`build/output/TripleA-中文版.dmg`（86MB，arm64），已验证可挂载、app 可启动到解析地图阶段。

### 第五轮：用户反馈"这次修改和上次没变化"——打包 bug 修复（关键！）
- **根因**：打包脚本 `JAR=$(ls game-app/game-headed/build/libs/*.jar | head -1)` 按字母序取到最旧的 15918.jar（目录里堆积了 15918/15919/15920/15921 多个版本），导致前几次打包 jpackage 一直把旧 jar 塞进 app。新代码（第四轮的 DisplayNameLocalizer 等）虽已编译进 15921.jar，却从未进入 DMG，所以用户界面看不到任何变化。旧 DMG 195MB 是因为塞了多个 jar。
- **诊断方法**：挂载 DMG → `ls app/Contents/app/*.jar` 看实际 jar 版本；`unzip -p <jar> <class> | python 解码查 CJK` 确认中文是否编入；对比新旧 jar 是否含新增 class。
- **正确打包**：建干净输入目录，只放最新的那一个 jar（按修改时间 `ls -t | head -1`，不要按字母序），`--input` 指向该目录。用 `game-headed-2026-11.16.15921.jar` 重打后：DMG 86MB（单一 jar），确认含 DisplayNameLocalizer.class，图标哈希与官方一致，挂载验证通过。
- **教训**：每次 jpackage 前必须确认 `--input` 目录里只有唯一一个最新 jar，绝不能用堆积了历史版本的 `build/libs` 目录直接打包。交付前务必挂载 DMG 核对 app 内 jar 版本与内容。
